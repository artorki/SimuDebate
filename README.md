# 🧠 SimuDebate

### Multi-Agent Debate Simulator in a 3D Virtual Environment

> **SimuDebate** یک شبیه‌ساز چندعاملی‌ست که چند Agent هوش‌مصنوعی با نقش‌ها، تخصص‌ها و مکاتب فکری متفاوت را در یک محیط سه‌بعدی قرار می‌دهد تا با رفتاری انسانی و به‌صورت علمی با هم مناظره و یکدیگر را به چالش بکشند.

کاربر به‌عنوان Host موضوع را تعیین می‌کند و Agentها به عنوان مهمان در طول مناظره استدلال‌های یکدیگر را بررسی، تأیید، رد و در صورت نیاز اصلاح می‌کنند. هر Agent نیز وضعیت شناختی مستقل خود را حفظ می‌کند.

---

## ✨ امکانات

### 🏢 محیط سه‌بعدی تعاملی

محیط Virtual Office با **Three.js** شامل:

* سالن جلسات
* کتابخانه
* بخش رایانه
* روابط‌عمومی
* بایگانی
* اتاق سرور

کاراکترها دارای رفتارها و Animationهایی مانند **Walking، Sitting، Typing، Reading، Searching و Talking** هستند.

### 📡 تعامل ایجنت‌ها و انسان‌ها در مناظره

انسان‌های حقیقی می‌توانند از طریق یک گروه تلگرامی، مناظره را دنبال کنند، صحبت ایجنت‌ها را نقد کنند، سوال بپرسند و از سمت ایجنت‌ها پاسخ‌شان را دریافت کنند.

### 📊 تحلیل و خروجی

* **Synthesis:** جمع‌بندی نهایی مناظره (نقاط توافق، اختلاف و مسیرهای پژوهشی)
* **Mindmap:** تولید و رندر گراف ارتباطی (با Mermaid.js)
* **JSON Export:** خروجی کامل لاگ مناظره (جهت تولید محتوای صوتی/تصویری)
* **Token & Cost Monitoring:** نمایش مصرف Token و هزینه‌ی تخمینی

### 🔀 مولتی‌مدل

دو حالت:

* **Single:** یک مدل برای همه‌ی Agentها
* **Multi:** مدل و Provider مستقل برای هر Agent

پشتیبانی فعلی از **OpenAI، Claude، Gemini و مدل‌های Local سازگار با OpenAI API**.

### ⚡ وقفه منطقی

سیستم می‌تواند پیش از هر نوبت بررسی کند که آیا **تناقض جدی، خطای فاحش یا حمله مستقیم** وجود دارد و در صورت نیاز یک وقفه‌ی کوتاه ایجاد کند.

### 🧠 حالت شناختی

هر Agent علاوه بر تاریخچه، یک State ساختاریافته دارد که شامل:
`beliefs`, `claims`, `supported_claims`, `challenged_claims`, `concessions`, `uncertainties`, `objectives` و `opponents` است.

### 💾 ماندگاری وضعیت

تنظیمات، تاریخچه، وضعیت Agentها، Mindmap و اطلاعات مناظره در `state.json` ذخیره و بازیابی می‌شوند.

### 🧩 مدیریت زمینه

در بحث‌های طولانی، به‌جای ارسال کل Transcript، ادعاهای ابتدایی و نوبت‌های اخیر نگه داشته می‌شوند تا Context کنترل شود.

## 🏗️ معماری

```text
Frontend
HTML + JavaScript
├── Three.js
├── TailwindCSS
└── Mermaid.js

        ↓ HTTP / JSON

Backend
Python + Flask
├── LLM Routing
├── Telegram API
├── State Persistence
├── Token Tracking
└── Cost Estimation
```

## 🎯 کاربردها

**پژوهش و تحلیل** — بررسی یک مسئله از چند دیدگاه

## ⚙️ اجرا

```bash
pip install flask flask-cors requests
python SimuDebate_server.py
```

سپس `simudebate.html` را در مرورگر اجرا کنید.

Backend به‌صورت پیش‌فرض روی:

```text
http://127.0.0.1:8765
```

در دسترس است.
